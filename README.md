В репозитории собраны SQL-решения четырёх лабораторных: проектирование базы данных музея, запросы к учебной базе, нормализация, триггеры и анализ планов выполнения.

## Запуск

Для базы музея нужны PostgreSQL и утилиты `createdb` и `psql`. Выполните из корня репозитория:

```bash
createdb museum_labs
psql -X -v ON_ERROR_STOP=1 -d museum_labs -f setup.sql
psql -X -v ON_ERROR_STOP=1 -d museum_labs -f labs/lab03/run.sql
psql -X -v ON_ERROR_STOP=1 -d museum_labs -f checks/museum.sql
```

`setup.sql` рассчитан на пустую базу. Он создаёт таблицы и загружает тестовые данные. Затем применяется нормализация и создаётся триггер. Последняя команда проверяет обновление статистики после вставки ремонта; тестовая запись откатывается.

Для работ 2 и 4 нужна университетская база «Учебный процесс». Её дамп в репозиторий не включён. Если база доступна под именем `ucheb`:

```bash
psql -X -v ON_ERROR_STOP=1 -d ucheb -f labs/lab02/queries.sql
psql -X -v ON_ERROR_STOP=1 -d ucheb -f labs/lab04/explain.sql
```

`labs/lab04/indexes.sql` содержит кандидаты на индексы. Перед запуском следует проверить уже существующие индексы базы. Файл не выполняется автоматически.

## Примечания к коду

Исходники восстановлены из учебных отчётов. При переносе второй работы исправлены дата и состав полей запроса об отчислении; уточнён подсчёт разных групп; убран дополнительный фильтр действующих записей при сравнении средних оценок; поиск однофамильцев оформлен через `EXISTS` с проверкой записей об обучении.

Миграция третьей работы реализует описанную в отчёте нормализацию: удаление избыточного `Work_Log.id_exhibit` и закрепление номера пропуска смотрителя как уникального непустого ключа.

Триггер сохраняет логику учебного решения: обновляет статистику после `INSERT` в журнал ремонтов. Представление считает записи журнала, группируя мастеров по ФИО; после изменения или удаления записей требуется отдельный `REFRESH MATERIALIZED VIEW mv_master_repairs`.

При подготовке проверены комплектность файлов и ссылки. Выполнение на PostgreSQL в этой среде не проверялось: сервер и дамп учебной базы недоступны. Численный выигрыш от индексов не заявляется.
